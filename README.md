# Trasa — транспорт Вильнюса и Вильнюсского края

Android-приложение: строит маршрут «откуда → куда» по расписанию городского транспорта Вильнюса, пригородных автобусов Вильнюсского района, междугородних рейсов, которые останавливаются в крае, и (экспериментально) поездов. Перед поездкой и во время неё присылает уведомления.

## Что умеет

- **Маршрут** — остановка, город, «моё место» (GPS) или точка на карте. Пересадки, в том числе пешком между соседними остановками. Показывает 2–4 варианта.
- **Карта-схема:** автобусы синие, троллейбусы красные, экспрессы (G) зелёные, междугородние жёлтые, поезда чёрные. Слои включаются и выключаются. Остановки появляются при приближении карты.
- **Контролёры** — кнопка «＋К» или долгое нажатие на карту. Отметка видна несколько часов (срок задаётся в настройках). Если отметка рядом с вашим маршрутом, в результатах появится предупреждение. Отметки хранятся только на вашем телефоне: открытых данных о контролёрах нет.
- **Напоминания** (по расписанию, без GPS):
  - за 60, 30, 10 и 1 минуту до выхода к первой остановке;
  - посадка: какая линия, направление, где выходить;
  - каждая проезжаемая остановка (можно отключить);
  - перед выходом: пересадка (на что, во сколько, откуда) или «ваша конечная»; отмечается, если это конечная маршрута;
  - пересадка и прибытие.
- **Поездки** — разовая поездка или регулярная по дням недели («Пн–Пт, после 07:30»). Регулярные пересчитываются на неделю вперёд при каждом открытии приложения.
- **Названия:** Вильнюс и Вильнюсский район по-польски, остальное по-литовски. Например, рейс «Wilno – Švenčionys», остановки «Dworzec», «Rondo Antokolskie», «Niemenczyn». Словарь неполный, любую остановку можно переименовать: Данные → Названия остановок.

## Источники данных (скачиваются на телефоне)

| Что | Откуда |
|---|---|
| Город Вильнюс | `https://www.stops.lt/vilnius/vilnius/gtfs.zip` |
| Вильнюсский район | `https://www.visimarsrutai.lt/gtfs/VilniausR.zip` |
| Междугородние (берутся только рейсы через край, ~40 км от центра) | `https://www.visimarsrutai.lt/gtfs/LTSAR.zip` |
| Поезда — экспериментально: из общего файла берутся только ж/д-маршруты, если они там есть | `https://www.visimarsrutai.lt/gtfs/google_transit.zip` |
| Соседние районы (по желанию) | `SalcininkuR`, `SvencioniuR`, `TrakuR`, `SirvintuR`, `Elektrenu` |

Если сайт недоступен, файл можно скачать в браузере телефона и загрузить кнопкой «ZIP с телефона».

## Как получить APK (бесплатно, без Android Studio)

1. Зарегистрируйтесь на <https://github.com>.
2. Нажмите **New repository**, назовите, например, `trasa`, и нажмите **Create**.
3. На странице репозитория нажмите **uploading an existing file** и перетащите **всё содержимое** распакованной папки `trasa` (вместе с папкой `.github`). Затем нажмите **Commit changes**.
   - Если папка `.github` не загрузилась (скрытые папки иногда пропускаются), откройте вкладку **Actions** → **set up a workflow yourself**, вставьте содержимое `.github/workflows/build-apk.yml` и сохраните.
4. Откройте вкладку **Actions**. Сборка «Сборка APK» идёт примерно 5–8 минут.
5. Когда появится зелёная галочка, откройте **Releases** (справа на главной странице репозитория) и скачайте **Trasa.apk** на телефон.
6. Установите APK, разрешив установку из этого источника. Откройте приложение → **Данные** → **Скачать / обновить выбранные**.
7. Разрешите уведомления. В **Данные → Точные будильники…** включите точные будильники, иначе Android может задерживать уведомления на несколько минут.

После каждого изменения файлов в репозитории GitHub соберёт новую версию сам.

### Сборка у себя (если есть Android Studio)

```bash
npm install
npm run vendor
npm run android:init
npx cap open android   # дальше Run ▶ в Android Studio
```

## Устройство

- `www/js/core/` — ядро без зависимостей: ZIP-ридер (`DecompressionStream`), потоковый CSV, импорт GTFS, сеть остановок с пешими пересадками, поиск пути (Connection Scan Algorithm), польские названия.
- `www/js/app.js` — интерфейс; `map.js` — Leaflet; `notify.js` — тексты уведомлений; `platform.js` — Capacitor: нативное скачивание без CORS, локальные уведомления, геолокация, IndexedDB.
- `test/` — синтетические GTFS-данные и тесты (`node test/core.test.mjs`).

## Ограничения

- Поиск идёт по расписанию: опоздания и отмены рейсов не учитываются.
- Поиск только «отправление после…» (нет режима «прибыть к…»).
- Поезда: открытого GTFS у LTG Link найти не удалось. Если в общем файле Литвы поездов нет, слой поездов будет пустым.
- Граница «Вильнюсского края» для польских названий приблизительная. Переключатель «строго / широкий край» есть в настройках.
